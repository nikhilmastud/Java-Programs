# Java Programs

A collection of Java programs created for learning and practicing **Java fundamentals, object-oriented programming, problem solving, and core programming concepts**.

## Topics

- Java syntax and fundamentals
- Variables, operators and control flow
- Arrays and strings
- Methods
- Classes and objects
- Object-oriented programming
- Basic exception handling
- Practice problems

## Purpose

This repository represents my early Java programming practice and provides a foundation for application development and Spring Boot learning.

> Learning repository — examples are intentionally kept beginner-friendly.
